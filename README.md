# 수학 연산 퀴즈

자연수 · 정수 · 유리수의 덧셈, 뺄셈, 곱셈, 나눗셈을 4지선다로 푸는 퀴즈 게임이에요.
HTML + CSS + 순수 JavaScript로 만들었고, 서버·빌드·인터넷이 필요 없어요.

## 실행 방법

1. 이 폴더 전체를 내려받아요. (`index.html`, `style.css`, `app.js`, `logic.js`, `questions.js`가 같은 폴더에 있어야 해요.)
2. `index.html`을 더블클릭해서 브라우저(Chrome, Edge, Safari, Firefox)로 열어요.

끝이에요. `fetch`를 쓰지 않아서 파일을 그냥 열어도 문제 데이터가 불러와져요.
(파일을 그냥 열면 앱 설치·오프라인 저장 기능만 빠지고 게임은 똑같이 동작해요. 아래 "앱으로 설치하기"는 웹 주소로 열 때 쓸 수 있어요.)

## 앱으로 설치하기 (PWA)

GitHub Pages 같은 `https://` 주소로 열면 휴대폰 홈 화면에 앱처럼 추가할 수 있어요. 주소창 없이 전체 화면으로 열리고, 한 번 열어 두면 **인터넷이 없어도** 실행돼요.

- **안드로이드(Chrome)**: 오른쪽 위 ⋮ 메뉴 → **앱 설치** 또는 **홈 화면에 추가**
- **아이폰(Safari)**: 아래 공유 버튼(□↑) → **홈 화면에 추가**
- **PC(Chrome, Edge)**: 주소창 오른쪽의 설치 아이콘(⊕) 클릭

처음 열 때는 인터넷이 필요하고, 그때 모든 파일이 기기에 저장돼요. 랭킹 기록도 그 기기에 저장돼요.

> 모든 카테고리를 빨리 확인하고 싶을 때: 주소 끝에 `?check=1`을 붙여 열면 퀴즈 화면에 "결과로 건너뛰기" 버튼이 생겨요. 이 버튼으로 끝낸 기록은 랭킹에 저장되지 않아요.

## 게임 규칙

- **모드**: 카테고리 20문제 / 영역 80문제 / 전체 240문제 (문제 순서는 매번 섞여요)
- **제한 시간**: 문제마다 30초. 시간이 다 되면 그 문제는 0점으로 넘어가요.
- **점수**: 정답이면 10점 + 속도 보너스 0~5점(남은 시간에 비례). 오답은 0점이고 감점은 없어요.
  - 20문제 카테고리 만점은 300점, 영역은 1200점, 전체는 3600점이에요.
- **틀린 문제만 다시 풀기**: 결과 화면 버튼. 연습용이라서 랭킹에는 저장하지 않아요.
- **소리**: 오른쪽 위 🔊 버튼으로 켜고 꺼요. 효과음은 브라우저가 직접 만들어서 소리 파일이 없어요.

## 랭킹

- 브라우저의 `localStorage`에만 저장해요. 서버가 없어서 **기기와 브라우저마다 따로** 쌓이고, 접속 주소(예: 내 컴퓨터의 파일 / GitHub Pages 주소)가 다르면 기록도 따로예요.
- 정렬: 점수 높은 순 → 동점이면 걸린 시간이 짧은 순 → 먼저 달성한 순
- 카테고리별 / 영역별 / 전체 탭으로 나뉘고, 각각 상위 10명을 보여줘요. 방금 한 기록은 "방금" 표시와 색으로 강조돼요.
- `localStorage`가 막힌 브라우저(예: 일부 비공개 창)에서도 게임은 되고, 기록이 저장되지 않는다는 안내가 나와요.
- 랭킹 화면 아래 **기록 지우기** 버튼으로 모든 기록을 지울 수 있어요(확인 후 삭제).

## 파일 구성

| 파일 | 하는 일 |
|------|---------|
| `index.html`, `style.css`, `app.js` | 화면과 게임 진행 |
| `logic.js` | 점수 계산 · 랭킹 정렬 (화면과 무관한 순수 함수) |
| `manifest.json`, `icons/` | 앱 이름·아이콘·전체 화면 설정 (PWA) |
| `sw.js` | 오프라인 실행을 위한 서비스 워커 |
| `questions.js` | 문제 240개 (`window.QUESTIONS`). 직접 고치지 마세요. |
| `gen_questions.py` | 문제 생성기 (`fractions`로 정답을 직접 계산) |
| `validate_questions.py` | 문제 데이터 검증 |
| `tests.js`, `test.html` | 점수 · 랭킹 테스트 |

## 문제 데이터 다시 만들기 (선택)

Python 3가 필요해요.

```
python gen_questions.py        # questions.js 생성 (시드 고정, 항상 같은 결과)
python validate_questions.py   # 240문제 검증, 하나라도 실패하면 종료 코드 1
```

## 테스트

- 브라우저: `test.html`을 열면 결과가 바로 보여요.
- Node.js가 있다면: `node tests.js` (실패가 있으면 종료 코드 1)

점수 계산(기본 10점, 보너스 0~5점, 만점 300점)과 랭킹 정렬(점수 → 시간 → 달성 순서), 종류별 순위, 저장 개수 제한, 망가진 저장값 걸러내기를 확인해요.

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만들어요. (예: `math-quiz`, Public)
2. 이 폴더에서 아래 명령을 실행해요. (`<내아이디>`와 저장소 이름은 바꿔 주세요.)

   ```
   git init
   git add .
   git commit -m "수학 연산 퀴즈"
   git branch -M main
   git remote add origin https://github.com/<내아이디>/math-quiz.git
   git push -u origin main
   ```

   웹에서 `Add file → Upload files`로 파일을 끌어다 놓아도 돼요. 게임이 동작하려면 `index.html`, `style.css`, `app.js`, `logic.js`, `questions.js`가 필요하고, 앱 설치와 오프라인 실행까지 되려면 `manifest.json`, `sw.js`, `icons/` 폴더도 함께 올려야 해요.
3. 저장소의 **Settings → Pages**로 가요.
4. **Build and deployment → Source**를 `Deploy from a branch`로, **Branch**를 `main` / `(root)`로 고르고 **Save**를 눌러요.
5. 1~2분 뒤 `https://<내아이디>.github.io/math-quiz/` 에서 게임이 열려요. 같은 화면 위쪽에 주소가 표시돼요.

배포한 뒤에는 `index.html`이 저장소 맨 위(루트)에 있어야 해요. 파일을 고쳐서 다시 `git push` 하면 몇 분 안에 반영돼요.

> **앱 파일을 고쳤다면 `sw.js` 맨 위의 `VERSION`(`"v1"` → `"v2"`)도 올려 주세요.** 앱은 저장해 둔 파일을 먼저 보여주기 때문에, 버전을 올려야 이미 설치한 기기가 새 파일로 바뀌어요. (새 버전은 다음에 앱을 열 때 받고, 그다음 실행부터 보여요.) `sw.js`의 `ASSETS` 목록에는 앱이 쓰는 파일이 모두 들어 있어야 해요.
랭킹은 방문한 사람 각자의 브라우저에만 저장되니, 여럿이 함께 쓰는 공용 랭킹은 아니에요.
