수학 연산 퀴즈의 통계를 계산해 보고해 주세요. 인자: $ARGUMENTS

## 데이터 출처

- **문제은행**: `questions.js`(`window.QUESTIONS = [...]`). 읽기만 하고 수정하지 않습니다.
- **플레이 기록**: 브라우저 `localStorage`의 `mathquiz.records.v1`에 있어 CLI에서 직접 읽을 수 없습니다. 인자로 내보낸 JSON 파일 경로가 주어졌을 때만 분석합니다. 경로가 없으면 문제은행 통계만 내고, 기록 통계를 보려면 브라우저 콘솔에서 아래를 실행해 JSON 파일로 저장하도록 안내합니다.
  ```js
  copy(localStorage.getItem("mathquiz.records.v1"))
  ```
- 기록 파일은 `logic.js`의 `sanitizeRecords`와 같은 기준(`nick`, `key`는 문자열이고 `score`, `correct`, `total`, `timeMs`, `at`은 유한한 수)으로 걸러, 제외한 항목 수를 함께 알려 줍니다.

`python`은 스토어 스텁일 수 있으므로 `%LOCALAPPDATA%\Programs\Python\Python313\python.exe`를 쓰고, 계산용 스크립트는 프로젝트 밖(스크래치패드)에 둡니다. Node는 없습니다.

## 1. 문제은행 통계

- 전체 문항 수와 영역(자연수/정수/유리수) × 연산(덧셈/뺄셈/곱셈/나눗셈) 12개 카테고리별 문항 수(기대값 20).
- 난이도 하/중/상 분포(카테고리당 기대값 7/8/5)와 정답 위치 A–D 분포(카테고리당 각 5).
- 기대값과 다른 카테고리는 따로 표시합니다.

## 2. 플레이 기록 통계 (기록 파일이 있을 때)

- 총 기록 수, 닉네임 수, 첫·마지막 플레이 일시(`at`).
- 모드별(`key`: `category:*` / `area:*` / `all`) 플레이 횟수, 평균·최고 점수, 평균 정답률(`correct/total`), 평균 소요 시간.
- 카테고리별 정답률: 정답률이 낮은 카테고리 상위 3개를 "취약 영역"으로 보고합니다.
- 닉네임별 플레이 횟수와 최고 점수.
- 만점 대비 점수 비율: 만점은 `문항 수 × (10 + 5)`입니다(`maxScore`).
- 한 모드의 기록이 100개(`RECORD_CAP`)에 도달했다면 알려 줍니다. 상위 100개만 남기므로 그 이하 기록은 통계에 없습니다.

## 3. 출력 형식

표를 위주로 간결하게 정리하고, 마지막에 눈에 띄는 점(기대값과 다른 분포, 취약 영역, 이상치 등)을 2~3줄로 요약합니다. 연습(retry wrong only) 플레이는 저장되지 않으므로 통계에 포함되지 않는다는 점도 한 줄로 밝힙니다.

사용자가 요청하기 전에는 프로젝트 파일을 수정하지 마세요.
