`teacher-data/records.json`에서 학생들을 나란히 비교해 주세요. 인자(비교할 닉네임들, 선택 사항으로 모드). 예: `민지 준호`, `민지 준호 area:int`, `민지` (닉네임 하나면 반 평균과 비교): $ARGUMENTS

파일이 없으면 `/teacher-import`를 먼저 실행하라고 안내하고 중단합니다. 지정한 닉네임이 없으면 비슷한 닉네임을 제안하고 중단합니다. 읽기 전용입니다.

## 비교 방식

- 지표는 `/teacher-overview`와 같은 정의(점수율, 문항 수 가중 정답률, 문항당 시간)를 씁니다. `flag`가 붙은 이상 기록은 제외합니다.
- 인자에 학생이 없으면 평균 점수율 상위 3명과 하위 3명을 자동으로 골라 비교합니다.
- 모드를 지정하지 않으면 **같은 모드(`key`)에서 기록이 모두 있는 경우만** 모드별로 비교합니다. 서로 다른 모드의 점수를 섞어 비교하지 않습니다(문항 수와 난이도가 다름).

## 출력

1. 요약 비교표 (학생을 열로):

   | 지표 | 학생A | 학생B | 반 평균 |
   |---|---|---|---|
   | 플레이 수 / 최고 점수 / 평균 점수율 / 정답률 / 문항당 시간 | | | |

2. 공통 모드별 표: 각 모드에서 학생별 최고 점수·평균 점수율, 우열(차이가 5%p 미만이면 "비슷함").
3. 카테고리(12개) 정답률 비교는 `category:*` 기록이 있는 경우에만 표로 보여 주고, 없는 칸은 `–`로 둡니다.
4. 속도 vs 정확도 해석 두세 줄: 예) "A는 더 빠르지만 정답률이 낮음".
5. 기록이 적어 신뢰하기 어려운 비교(한쪽 기록 2개 이하)는 명시합니다.

계산용 스크립트는 스크래치패드에 두고 Python(`%LOCALAPPDATA%\Programs\Python\Python313\python.exe`, `PYTHONIOENCODING=utf-8`)으로 실행합니다. 프로젝트 파일은 수정하지 않습니다.
